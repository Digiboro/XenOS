# Правила комментирования

## Язык комментариев

- Все комментарии в коде должны быть на **русском языке**
- Это касается как обычных комментариев (`//`), так и документации (`///`, `//!`)

## Стиль комментариев

- Комментарии начинаются с заглавной буквы и заканчиваются точкой (даже если это одно предложение)
- Между `//` и текстом должен быть пробел

```rust
// Правильно: Инициализируем буфер.
// Неправильно: инициализируем буфер
```

## Tagged комментарии

Специальные теги пишутся заглавными буквами с двоеточием:

- `// TODO:` — задачи для реализации
- `// FIXME:` — известные проблемы требующие исправления
- `// SAFETY:` — объяснение безопасности unsafe блока (см. `safety.md`)
- `// NOTE:` — важные заметки для понимания кода

```rust
// TODO: Реализовать полноценную fault-safe проверку.
// FIXME: Ошибка должна обрабатываться корректно.
// SAFETY: Указатель проверен на null выше.
// NOTE: Порядок инициализации критичен.
```

## Документация vs комментарии

- `///` и `//!` — для **пользователей** API (документация)
- `//` — для **разработчиков** (детали реализации)

Комментарии описывают *как* работает код, документация — *что* он делает и *как* его использовать.
