# Общие правила проекта XenOS

**ВНИМАНИЕ: Данные правила критически важны для соблюдения.**

Проект XenOS является проектом ОС с NT совместимым ядром на уровне API и архитектуры.
Ядро написано на Rust и совместимо с Windows NT6.1

**Основной ориентир реализации: Windows NT 6.1 (Windows 7)**
При создании внутренних структур, названий и сигнатур нужно ориентироваться на реализацию в Windows NT 6.1 (Windows 7).
Это касается всех элементов ядра и сопутствующих подсистем:

- Структуры данных ядра (KTHREAD, EPROCESS, IRP и т.д.)
- Системные вызовы (syscalls) и их параметры
- Внутренние API ядра (Nt*, Zw*, Ke*, Ex*, Ps*, Mm*, Io\* и т.д.)
- Механизмы синхронизации и планирования
- Управление памятью и виртуальными адресными пространствами
- Подсистема ввода-вывода (I/O Manager)
- Управление процессами и потоками
- И другие компоненты ядра

**Важно: Основной формулировкой при описании реализации должно быть "соответствие NT архитектуре" (или "соответствие архитектуре Windows NT").**
ReactOS, Windows XP и другие реализации упоминаются только как источники в ссылках на файлы и документацию, но не как основной ориентир соответствия.

В процессе анализа и проработки решения надо анализировать реализацию в исходниках:

- **MSDN (Windows 7 / NT 6.1)** - **приоритетный источник** для документации API, структур данных и поведения системы
- Windows XP (docs/ref/nt5src/XPSP1) - источник для понимания эволюции API и обратной совместимости
- Windows 2003 Server (docs/ref/nt5src/Win2K3) - источник для понимания эволюции API и обратной совместимости
- ReactOS (docs/ref/reactos) - источник для анализа референсной реализации
- Другие релевантные источники

Допускается отступление если этого требует язык Rust или другие обстоятельства, но только с уведомлением пользователя.
