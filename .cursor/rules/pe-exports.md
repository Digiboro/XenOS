# PE exports / imports (контракт совместимости)

Экспортируемые из PE модулей символы (`ntoskrnl.exe`, будущие `hal.dll`, `.sys`) — это внешний ABI-контракт.
Правила жёсткие и обязательные:

- **Сигнатуры и поведение экспортируемых функций должны на 100% совпадать с MSDN/WDK (NT6.1 ориентир), любой ценой.**
- **Нельзя "временно" менять/упрощать экспортируемые сигнатуры.** Если функция ещё не реализуема — меняем внутренние контракты/подсистемы, но не экспорт.
- Для каждого добавляемого экспорта требуется:
  - ссылка на MSDN/WDK (приоритетный источник) в docstring;
  - проверка корректности сигнатуры/ABI/семантики по MSDN/WDK перед добавлением;
  - проверка, что в проекте нет уже экспорта с таким же NT-именем.
- Все комментарии/описания экспортов — на русском языке.
