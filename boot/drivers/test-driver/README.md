# Test Boot Driver (test-driver.sys)

Минимальный тестовый boot-драйвер для проверки механизма загрузки boot-драйверов в XenOS.

## Описание

`test-driver.sys` - это простейший boot-драйвер, который:

- Экспортирует функцию `DriverEntry` как точку входа
- Регистрирует функцию выгрузки `DriverUnload`
- Возвращает `STATUS_SUCCESS` при загрузке
- Не создает никаких устройств (для тестирования достаточно успешной загрузки)
